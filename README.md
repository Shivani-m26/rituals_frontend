# Rituals - Mindful Habit Tracking & Journal Sanctuary (Frontend)

Built with **Angular 19**, **Tailwind CSS**, and **RxJS**.

## ✨ Key Features
- **Authentication & Security:** JWT-based stateless auth, real email domain validation, welcome emails, 7-day inactivity security alerts, and full self-serve password reset.
- **Mindful Journal:** Personalized journal entries with custom styling and reflection history.
- **Habit Tracking:** Streak tracking, points system, and automated daily email reminders.
- **Gamification & Leaderboard:** Milestone badges and community ranking.

## 🚀 Live Deployment
- **Frontend (Vercel):** Connected to `main` branch.
- **Backend API (Render):** `https://rituals-backend-3.onrender.com`

## 🛠️ Local Development
```bash
npm install
npm start
```
Runs at `http://localhost:4200/`
